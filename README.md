# kaji-buddy
 
**家事の記録を、誰かに責められるためではなく「頑張った自分を認める」ためのものに。**
 
<img src="https://github.com/user-attachments/assets/9745d608-5f04-4a48-b0b2-f19314a5397d" alt="今日の家事リスト画面" width="320">
- **アプリURL**：https://kaji-buddy.onrender.com/
<br>
## サービス概要
 
日々の家事を「家事帳」に登録し、今日やる家事をリスト化して、完了するたびに実施時間を記録するライフログアプリです。
記録した瞬間に、選んだ応援キャラクターが状況に合わせた言葉で労ってくれます。
 
一般的な家事アプリが「公平な分担」や「ポイント競争」を目的にしているのに対し、kaji-buddy は**自分専用の記録**として設計しています。
誰かと比べたり、誰かに見張られたりせず、「自分はちゃんとやっている」を時間と数字で確かめられる場所を目指しました。
 
<br>
## 開発の背景
 
家事は毎日欠かせないのに、終わってしまえば形に残らず、誰にも気づかれにくい作業です。自分自身が家事を担う中で、その積み重ねが見えないことに孤独を感じていました。
 
家事を記録・可視化するアプリはすでにありますが、多くは分担の公平さやポイント競争を目的としていて、記録することが「評価」や「監視」のように感じられる場面もあります。
そこで、記録を**誰かと比べるためではなく、自分の頑張りを自分で認めるための道具**にしたいと考え、このアプリを作りました。
 
<br>
## 想定ユーザー
 
- 家事を多く担っていて、その頑張りを誰にも気づかれず孤独を感じている人
- 自分が抱えている家事の量や時間を把握し、暮らしを整えたい人
- 家事の記録を続けたいが、ToDoアプリでは達成感が得られず続かなかった人
<br>
## 主な機能
 
### 1. 家事帳（家事のテンプレ登録＆手順書）
 
<img src="https://github.com/user-attachments/assets/556c95ed-f097-47ef-bac8-a7a238799fb5" alt="家事帳画面" width="320">
家事を「名前・想定所要時間・カテゴリ・道具・手順メモ」のセットで登録し、何度でも使い回せる“家事の型”を作れます。
アプリが用意した共通家事も利用でき、カテゴリタブで絞り込めます。手順メモは自分専用の手順書として機能します。
 
### 2. 今日の家事リスト・記録
 
<img src="https://github.com/user-attachments/assets/42f46e47-de18-4618-a65c-df00d7a8db89" alt="家事帳から今日のリストに追加する動作" width="320">
家事帳から今日やる家事をまとめて選び、リストに追加します。選ぶたびに追加分の合計時間がその場で表示されるので、無理のない量を決められます。
完了ボタンを押すと実施時間が記録され、件数・実施時間・完了率のサマリーが**ページ遷移なしで更新**されます。
 
### 3. 「お疲れ様」フィードバック
 
<img src="https://github.com/user-attachments/assets/f524a3ee-adcc-4953-91a8-f3fe7c676f65" alt="お疲れ様フィードバックの動作" width="320">
完了するたびに、応援キャラクターがトーストでメッセージを届けます。
「全部完了」「目安より早い」「今日◯個目」など状況に応じて言葉が変わり、話し手は **ともだち／コーチ／執事** の3種類から選べます。
 
| ともだち | コーチ | 執事 |
| --- | --- | --- |
| やったね。ちゃんとやることやってえらいな | 目安よりも5分短縮！自己ベスト更新だ！ | 本日のご予定、すべて完了でございます。どうぞごゆるりとお過ごしください |
 
### 4. 記録一覧（これまでの歩み）
 
<img src="https://github.com/user-attachments/assets/ef8999dd-7d58-491f-ae7a-f8dd3940426c" alt="記録一覧画面" width="320">
今週の記録を日付ごとに振り返り、合計実施時間を確認できます。目安より早く終わった家事にはその旨を添えて表示します。
 
<br>
## こだわったポイント
 
**責めない設計**
記録がない週には「ゆっくり過ごせていたら、それも大切な時間です」と表示するなど、記録できなかったことを責める表現を使わないようにしています。今後追加予定のゲーミフィケーションでも、途切れた瞬間に罪悪感を生む「連続記録（ストリーク）」はあえて採用せず、リセットされない累積を指標にする方針です。
 
**記録のハードルを下げる**
実施時間の入力欄には想定所要時間を初期値として入れ、空欄のまま完了しても記録できるようにしています。家事を記録すること自体が新しい家事にならないよう、ワンタップで完了できることを優先しました。
 
**褒め言葉のマンネリ化を防ぐ**
同じ言葉を繰り返すと報酬として機能しなくなるため、状況別の出し分け・複数文言からのランダム表示・キャラクター選択を組み合わせ、毎回少し違う体験になるようにしています。
 
<br>
## 技術的な工夫
 
- **Turbo Stream による部分更新**：完了・取り消し時に、対象の行・サマリー・フィードバックのトーストだけを差し替え、JavaScript の記述を最小限に抑えつつ快適な操作感を実現しました。
- **ロジックを PORO に切り出し**：フィードバック文言の判定（`FeedbackMessage`）や1日の集計（`DailyChoreSummary`）をテーブルを持たない Ruby クラスに分離し、コントローラーとビューをシンプルに保ちつつ単体でテストできるようにしました。
- **共通家事とユーザー家事を1テーブルで管理**：`chores.user_id` を NULL 許容とし、NULL を全ユーザー共通の家事として扱う設計にしました。閲覧範囲はスコープ（`Chore.for_user(current_user)`）で制御しています。
- **データ整合性の担保**：「同じ日に同じ家事は1件まで」「1エントリーにつき記録は1件まで」をバリデーションと DB 制約の両方で保証し、記録のあるエントリーは削除できないようにしています。
- **品質管理の仕組み化**：GitHub Actions で PR ごとに RSpec・RuboCop・Brakeman などを実行し、SimpleCov でカバレッジを計測、Bullet で N+1 を検知しています。
- **認証ライブラリの選定**：当初は Sorcery を予定していましたが、認証はこのアプリの差別化要素ではないため、成熟していて実装が速い Devise に切り替え、家事記録と肯定体験の作り込みに時間を使いました。
